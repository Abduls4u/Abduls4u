I care less about collecting frameworks and more about understanding why systems are designed the way they are.

A working application is the beginning, not the finish line.

- 🔍 What happens when the system fails?
- ⚡ How does it behave under concurrent requests?
- 🗄️ What happens when the database becomes a bottleneck?
- 🤝 How should multiple engineers collaborate on the same codebase?
- 🛡️ How do we design for reliability without unnecessary complexity?
- 🔬 What happens beneath the abstractions?

These are the questions shaping the engineer I'm becoming.
